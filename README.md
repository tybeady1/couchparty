# Fairway Android Launch Monitor

Experimental Android camera launch monitor with local practice sessions and offline 3D golf games. Android 8.0+ (API 26), compiled with API 34. No third-party runtime dependencies.

## Live camera

Open Live Camera from Practice. Choose swing or indoor putting, choose the ball type, calibrate the visible frame width at the ball's plane, and tap the stationary ball. Wait for READY, then swing or putt. The detector follows visible ball motion and rearms for the next stationary ball. Setup Guide shows phone placement; a standalone diagram is in `docs/phone-setup.svg`.

Supported ball profiles: normal, range, foam and wiffle. Ball selection labels readings; it does not invent full-ball-equivalent speed. Side-view swings estimate visible image-plane speed and launch angle. Overhead putting estimates speed and image-plane direction. Spin, 3D velocity and carry are not measured. Low frame rates, blur, lighting, camera motion and perspective can cause missed or incorrect detections. Real ball tracking still needs physical-device field validation.

Imported video analysis is also available. Calibrate the frame width, select a clip and time offset, analyze, and inspect the tracked points before saving. The analyzer rejects insufficient tracks. Live and imported camera estimates remain separate from manual/demo session metrics.

## Practice and sessions

Select a club, enter manual readings or use the explicitly labeled demo source. Tap a recent shot for details/deletion. Finish and save a session to archive it. Settings controls ball type, units and CSV export. CSV uses yards, mph, degrees and rpm with source and ball type labels. App-private storage persists sessions and settings; uninstalling clears them. Export data you want to keep.

## Fairway Play

Open **Fairway Play** from Practice. The offline 3D range offers Free Practice, Target Rush (10 balls), Color Chase (called targets), and Distance Ladder (six distances). Meadow Links and Castle Cove each have three mini-golf holes with obstacles, moving gates, stroke counts and scorecards; Castle Cove includes water penalties. Touch controls and one-shot live-camera input are supported. Flight and roll use arcade physics, not measured carry or spin. No affiliation with Topgolf.

Models come from [Kenney Minigolf Kit 3.1](https://kenney.nl/assets/minigolf-kit), CC0. Original selected assets and license are in `third_party/kenney-minigolf`; bundled meshes are generated by `scripts/convert_models.py` (Python with Pillow).

## External simulators

Settings > **Connect to a golf simulator** supports OpenShotGolf, HeckleGolfSim, Open Connect/GSPro, OpenGolfSim and a custom JSON feed. Sending is disabled by default. See [connection instructions and compatibility matrix](integrations/README.md). Native adapters require explicit gameplay assumptions because the camera does not measure spin or complete 3D velocity. Protocol/socket tests pass; gameplay in external simulators has not been verified. INTERNET permission enables these opt-in LAN connections. The built-in games work offline.

## Build and checks

Requires JDK 17 and Android SDK platform 34 / build-tools 34.0.0. Use JDK 17 with the direct SDK builder to avoid old D8 compatibility problems with JDK 21.

```powershell
./scripts/build.ps1 -Sdk D:\Android_SDK -JavaHome D:\Androids\jbr
& D:\Android_SDK\platform-tools\adb.exe install -r ./build/Fairway-debug.apk
./scripts/test.ps1
./integrations/test.ps1
```

The APK is debug signed for local testing. Android Studio can open this directory using the included Gradle 8.9 wrapper. Alternatively, with JAVA_HOME pointing to JDK 17:

```powershell
./gradlew.bat assembleDebug lintDebug
```

Source is in `app/src/main/java/com/fairway/monitor/`. `LiveShotDetector` and `BallTracker` provide camera tracking; `Shot` handles practice metrics; `MainActivity` owns sessions/settings. `GolfGame` provides deterministic arcade rules, `GolfRenderer` draws bundled meshes, and `GameActivity` supplies controls and live-camera handoff. Simulator adapter details and tests live in `integrations/`.
