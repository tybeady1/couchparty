# Changelog

## 1.3.0 (build 4)

- Calibrate your putting mat from measured natural stopping distances, in metres or feet.
- Show estimated full rollout separately from the observed camera segment.
- Keep up to 10 distinct calibration putts per ball type, with edit/reset controls and out-of-range speed labels.

## 1.2.0 (build 3)

- Show an automatic results screen after a practice putt: camera-relative heading, observed trace, speed, observed distance and track details.
- Return to the camera with Next putt; game inputs continue straight to the game.
- Label observed distance separately from unmeasured full rollout; save observed distance with live history.

## 1.1.0 (build 2)

- Added app version display, manual update checks, APK download and Android installer handoff.
- Verify update package, version, SHA-256 checksum and installed-app signing key.
- Improve camera target selection feedback and calibration prompts; add center-target fallback.
- Includes offline range games, two mini-golf courses and simulator adapters.

## 1.0 (build 1)

Initial phone-test builds. These shared one version number; Git history starts with the final working snapshot.
